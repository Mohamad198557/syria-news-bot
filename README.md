# بوت أخبار الاقتصاد السوري

نسخة جاهزة لمستودع https://github.com/Mohamad198557/syria-news-bot . تجمع عناوين الأخبار العربية وروابطها من RSS وتفلتر الأخبار الاقتصادية التي تذكر سوريا أو مدنها، ثم تنشر في قناة تليجرام.

## التثبيت في مستودعك

1. فك ضغط الحزمة وارفع محتويات مجلد `syria-economic-bot` إلى **جذر المستودع** على الفرع `main`. لا ترفع ZIP نفسه أو المجلد كطبقة إضافية.
2. استبدل ملف `.github/workflows/syria_bot.yml` القديم بالملف المرفق في **المسار نفسه**. الملف القديم يشغّل `bot.py` غير الموجود؛ الجديد يشغّل `main.py`. تأكد من رفع المجلد المخفي `.github` أيضاً. يمكن فتح الملف القديم في GitHub ثم الضغط على Edit ولصق المحتوى الجديد.
3. أضف البوت مشرفاً إلى القناة مع صلاحية نشر الرسائل.
4. في Settings → Secrets and variables → Actions → Secrets أضف أو راجع:
   - `BOT_TOKEN`: التوكن من BotFather؛ لا تضعه داخل الكود أو المحادثة.
   - `CHAT_ID`: معرّف قناة النشر. إذا كانت القناة السابقة هي المقصودة فاستخدم `-1003803988944`، وإلا أدخل معرّف القناة الجديدة. لم نثبت معرّف القناة في الكود.
5. من Actions اختر **Syria Economic News** ثم Run workflow على `main` واترك `dry_run` مفعلاً. يعرض السجل الأخبار المرشحة دون إرسال أو تعديل سجل الأخبار.
6. بعد مراجعة المعاينة، من تبويب Variables أضف متغير مستودع باسم `ECONOMY_BOT_ENABLED` وقيمته `true`. بعدها يبدأ النشر في التشغيلات المجدولة؛ وللتجربة الفورية أعد Run workflow وألغِ `dry_run`.
7. يجب أن تسمح إعدادات Actions بالكتابة إلى محتويات المستودع. حفظ سجل الإرسال يحتاج السماح للـ workflow بالدفع إلى `main`؛ إن كانت حماية الفرع تمنع ذلك فعدّل إعداداتها بما يناسبك قبل تفعيل النشر.

لإيقاف النشر مع بقاء المعاينة: غيّر `ECONOMY_BOT_ENABLED` إلى `false`. لتعطيل التشغيل بالكامل: Disable workflow في Actions.

## السلوك

- التشغيل في الدقيقتين 10 و40 من كل ساعة، بحد أقصى 8 أخبار في الجولة. جدول GitHub بتوقيت UTC، وقد تتأخر التشغيلات؛ ليس خدمة عاجل لحظية مضمونة.
- يقبل فقط الأخبار ذات تاريخ نشر مفهوم خلال آخر 24 ساعة؛ يتجاوز الأخبار عديمة التاريخ أو المستقبلية بأكثر من 10 دقائق. في أول تشغيل قد يرسل ما يصل إلى 8 أخبار حديثة من هذه النافذة.
- يشترط إشارة لسوريا أو مدينة سورية وموضوعاً اقتصادياً. يجب أن يظهر أحدهما في العنوان، ويمكن أن يظهر الآخر في الملخص. لا يعتبر كل خبر من مصدر سوري اقتصادياً أو محلياً تلقائياً.
- أمثلة: عقوبات اقتصادية على سوريا، تصدير الكهرباء من الأردن إلى سوريا، أسعار الوقود والليرة السورية. يتجاوز الرياضة والسياسة العامة وأسعار النفط العالمية بلا ارتباط سوري واضح.
- الفلترة بقواعد وكلمات وليست فهماً دلالياً شاملاً: يمكن أن تفوّت خبراً مهماً أو تقبل خبراً هامشياً. التأثير الإقليمي غير المذكور صراحةً لا يستنتجه البوت. راجع المعاينة وعدّل `SYRIA` و`ECONOMY` في `main.py` عند الحاجة.
- ينشر العنوان، اسم المصدر، تاريخ الخبر بتوقيت دمشق، ورابط الأصل مع معاينة تليجرام إن توفرت. لا ينسخ المقال كاملاً ولا يولّد ملخصاً أو يضيف وصف «عاجل» تلقائياً. المصادر الحالية عربية فلا يحتاج خدمة ترجمة.
- يمنع التكرار بالرابط بعد إزالة معاملات التتبع وبالعنوان المطابق بعد تطبيع الكتابة. اختلاف صياغة العنوان والرابط قد يؤدي إلى نشر تغطيتين للحدث نفسه؛ لا يدّعي اكتشاف التطابق الدلالي.
- يسجل التسليم بعد تأكيد Telegram فقط، ويحفظ فور كل خبر إلى `data/sent_economy.json`. يحفظ GitHub الملف حتى إن فشل خبر لاحق، ويحتفظ بالمفاتيح نحو 30 يوماً. التشغيلات متسلسلة لمنع السباق.
- لا يوجد ضمان «مرة واحدة بالضبط»: انقطاع الشبكة بعد قبول تليجرام أو فشل دفع السجل إلى GitHub قد يؤدي لتكرار لاحق. عند فشل حفظ السجل راجع التشغيل واستعد ملفه من Artifacts قبل إعادة النشر. لا تعِد رفع ملف الحالة الفارغ بعد بدء العمل.
- سجل البوت السابق `sent_articles.txt` لا يُحذف ولا يُستورد؛ هذا البوت يستخدم سجلاً منفصلاً. قد تظهر أخبار سبق أن نشرها البوت القديم. لا تشغّل نسختين ناشرتين للقناة نفسها أثناء الانتقال.

## المصادر والإعدادات

المصادر في `config.json`. بتاريخ 2026-10-11 نجح التحقق من RSS عنب بلدي والجزيرة نت. رابط سانا أعاد محتوى غير قابل لتحليل RSS، لذا هو موجود لكنه معطّل. يمكن إضافة مصادر عربية أخرى بعد التحقق منها. المصدران الحاليان لا يضمنان تغطية كل الأخبار الاقتصادية السورية؛ RSS قد يحتفظ بعدد محدود من الأخبار فقط. يفحص البرنامج كل عناصر الخلاصة المتاحة.

غيّر `max_age_hours` للنافذة الزمنية و`max_posts_per_run` للعدد الأقصى إلى أعداد موجبة. فشل مصدر لا يمنع بقية المصادر؛ فشل الجميع يجعل التشغيل يفشل بوضوح.

## تشغيل محلي

Python 3.11 أو أحدث، دون حزم خارجية:

```sh
python -m unittest discover -s tests -v
python main.py --dry-run
```

للنشر المحلي اضبط `BOT_TOKEN` و`CHAT_ID` في متغيرات البيئة ثم شغّل `python main.py`. بوابة `ECONOMY_BOT_ENABLED` تخص GitHub Actions؛ التشغيل المحلي دون `--dry-run` يرسل فعلياً. لا تشغّل النشر المحلي بالتزامن مع GitHub.
